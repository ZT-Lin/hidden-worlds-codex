# 变体水手：海盗 Variant Sailor: Pirate

你在由一个恐怖的海盗抚养长大，这个残忍的杀人犯教会了你如何在血腥而危险的世界中生存。期间，你沉溺于在公海上劫掠，并将那些无辜者送入海底。熟悉恐惧和杀戮滋味的你，成为了许多港口间流传的恶名。

当决定在你的航海生涯中加入海盗元素时，则你可以用**恶名**特性（见边栏）代替**船家路子**特性。

## 变体特性：恶名 Variant Feature: Bad Reputation

如果你的角色使用水手背景，则你可以选择这个背景特性代替**船家路子**特性。

无论你走到哪里，人们都会因你的恶名而恐惧。你在身处文明社区时，可以免受一些细微的犯罪指控（例如在酒馆吃霸王餐或者踢坏商店的大门等），只因人们不敢冒险向当局告发你的劣行。
