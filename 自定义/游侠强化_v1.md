# 宿敌：

保留原版宿敌选择。

每回合一次，当你在自己的回合对你的宿敌使用的武器攻击命中时，你的伤害掷骰带有优势

>个人规则：每回合一次，当你在自己的回合对你的宿敌使用的武器攻击命中时，你可以在伤害掷骰时额外加入一个武器伤害骰。

# 自然探索者：

移除下列效果，可视为[[感知]]（[[求生]]）检定：

- 除非受魔法效应影响，否则你的队伍不会迷路。
- 你的队伍旅行时不会因困难地形而变慢

在非偏好地形移动一小时或更长时间时，你可以在长休结束时，选择将当前地形与你已有的偏好地形之一替换。在完成一次长休前，不能再次替换。

在偏好地形移动一小时或更长时间时，你进行的[[驯兽]]、[[求生]]、[[察觉]]检定获得优势。

# 原初意识：

消耗一枚法术位，并使用[[动作]]将你的意识与原初意识相连，你可以选择获得以下增益之一，持续一分钟，所消耗法术位每提高一环阶，持续时间就多加 1 分钟：

- 你的意识集中在身处的区域，感测 1 里内是否存在以下类型生物 （在偏爱地形中时，扩展至 6 里）：异怪、天界生物、龙、精类生物、邪魔、元素生物和不死生物。另外，该特性并不会知晓生物的位置或数量。
- 你的意识集中在身处的周围，感测 100 尺（在偏爱地形中，扩展至 300 尺）内生物的可能位置。此特性获得的生物的位置不等于确切看见。
- 你的意识高度集中，当你首次因受到伤害而进行维持专注的[[体质]][[豁免]]时，该[[豁免]]获得优势。

# 多面手（6级）：

每回合一次，你可以收起一把近战武器并抽出一把远程武器，或者收起一把远程武器并抽出一把近战武器。此行为不消耗你的[[动作]]，也不消耗你每回合一次的免费物品互动（Free Object Interaction）。

# 遁术 -> 连招（10级）：

当你施展一个法术并使一个或多个敌对生物受到该法术影响时，你可以选择受到影响的其中一个生物，直到你的下回合结束前，由你发起的针对该生物的首次[[攻击]]检定获得优势。

# 无踪步（14级）

第 14 级起，你可以在自己回合以一个[[附赠动作]]的形式执行[[躲藏|躲藏 Hide]] 动作。此时，你无法被非魔法手段追踪到，除非你主动留下踪迹。

# 野性感官（18级）

第 18 级时，你获得超自然的感官以帮助你对抗看不到的生物。此后，你[[攻击]]一个看不到的生物时不会因此承受劣势。

另外，你还能感测 30 尺内所有[[隐形]]敌人的位置，前提是该生物并没有针对你进行[[躲藏]]，而你也没有陷入[[目盲]]或[[耳聋]]。

# 屠灭众敌（20级）

你在自己的每个回合内，都有一次机会将你的感知调整值加到你对目标进行的攻击检定或伤害掷骰上。

你可以在掷骰之前或者之后决定使用该特性，但必须在该掷骰的相关效应被应用之前。
