# 宿敌（1级）

保留原版宿敌选择。

当你获得额外选择一个宿敌的机会时，可以替换一个已有的宿敌。

每回合最多一次，你可以将你的感知调整值加入对宿敌的伤害掷骰。

# 自然探索者（1级）

移除下列效果，可视为感知（求生）检定：

- 除非受魔法效应影响，否则你的队伍不会迷路。
- 你的队伍旅行时不会因困难地形而变慢

随后，在非偏好地形长休时，你可以花费一小时研究当前地形，将其与你已有的偏好地形之一进行替换。在完成一次长休前，不能再次替换。

在偏好地形移动一小时或更长时间时，你进行的驯兽、求生检定获得优势。

# 原初意识（3级 游侠泛型）

消耗一枚法术位，并使用动作将你的意识与原初意识相连，你可以选择获得以下增益之一，持续一分钟，所消耗法术位每提高一环阶，持续时间就多加 1 分钟：

- 你的意识集中在身处的区域，感测 1 里内是否存在以下类型生物 （在偏爱地形中时，扩展至 6 里）：异怪、天界生物、龙、精类生物、邪魔、元素生物和不死生物。另外，该特性并不会知晓生物的位置或数量。
- 你的意识集中在身处的周围，若你没有陷入耳聋，你可以感测 60 尺内所有未对你处于完全掩护的生物的所在位置（在偏爱地形中，延伸至 90 尺内的所有生物）。此特性获得的生物的位置不等于确切看见，并且你无法确定其身份、性质或意图。

同时，你可以用空手触碰一个自愿的生物建立心灵感应，直到该生物脱离你的触碰前，你无需语言交流便可共享你获得的信息。

# 专心（6级 宿敌 自然探索者）

第 6 级起，你愈发熟练地与原初意识进行连接。你可以在施展一个需要专注的法术的同时，作为该法术的一部分进入原初意识状态，无需消耗法术位，持续时间等同于该法术的专注时间。

# 7级 游侠泛型

# 游击战术 （8级 属性值提升）

你执行疾走 Dash 动作时，你可以作为该动作的一部分，对攻击范围内的一个生物发起一次具有劣势的武器攻击。

另外，在抵抗魔法制造或控制的植物造成的移动障碍效应时（例如纠缠术 entangle），你的豁免检定具有优势。

# 9级 三环法术

# 落难追击（10级 自然探索者）

每回合最多一次，你攻击一个受到你或你的盟友的魔法造成的移动障碍效应的生物时，你可以额外造成 1d8 点与手持武器伤害类型相同的伤害。如果该生物是你的宿敌，则提升至 1d10。

# 威慑攻击（14级 宿敌）

第 14 级起，你可以在自己回合以一个附赠动作的形式执行躲藏 Hide动作。此时，你无法被非魔法手段追踪到，除非你主动留下踪迹。

另外，在躲藏期间，你对你攻击范围内的宿敌的行踪保持高度警惕。当攻击范围内某个你能看见的宿敌对盟友进行攻击时，你可以用一个反应对其执行一次攻击，本次攻击的伤害掷骰不获得你的属性调整值加成，除非是负数。

如果你的攻击命中，该生物的本次攻击检定具有劣势。

# 17级 五环法术

# 野性感官（18级 原版）

第 18 级时，你获得超自然的感官以帮助你对抗看不到的生物。此后，你攻击一个看不到的生物时不会因此承受劣势。

另外，你还能感测 30 尺内所有隐形敌人的位置，前提是该生物并没有针对你进行躲藏，而你也没有陷入目盲或耳聋。

# 19级 属性值提升

# 屠灭众敌（20级）

你在自己的每个回合内，有一次机会将感知调整值加到一个未命中的攻击检定中，若成功命中，则你可以指定此次伤害掷骰中的一颗武器伤害骰，视为取最大值。

你可以在掷骰之前或者之后决定使用该特性，但必须在该掷骰的相关效应被应用之前。
