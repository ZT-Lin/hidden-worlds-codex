对于单独冒险的冒险者回合机制补偿。

冒险者单独冒险时，将会获得更多的流畅度。每个回合开始时，你可以获得额外行动点 Bonus Action Points（BAP）：$遭遇难度系数 \times 遭遇数量倍率（向上调整）$。回合结束时重置，直到战斗结束前，你的 BAP 不会因为敌对生物数量增加或减少而改变。

| 遭遇难度 | 系数  |
| :--- | :-: |
| 简单   | 0.5 |
| 中等   |  1  |
| 困难   |  2  |
| 致命   |  3  |

| 遭遇数量  | 倍率  |
| :---- | :-: |
| 1     |  1  |
| 2     | 1.5 |
| 3~6   |  2  |
| 7~10  | 2.5 |
| 11~14 |  3  |
| 15+   |  4  |

例如，你是一名一级冒险者，单独冒险，但是遭遇了 3 只地精（150xp），低于三人冒险者小队应乘以下一阶倍率2.5，实际 375xp，严重超出了致命等级遭遇。

为了保证游玩体验，你可以获得 $3 \times 2.5 = 7.5 \rightarrow 8$ 个额外行动点。在你的回合内，你可以消耗行动点数执行额外的动作，具体费用参照下表：

> [!caution] 若攻击、法术未命中或目标豁免成功，你不可再次购买对应行动。

| 行动                                |  费用   |
| :-------------------------------- | :---: |
| 移动（5 尺）                           |   1   |
| 动作（攻击）【你不可通过此方式获得高于自身动作允许的最大攻击次数】 | 次数\*2 |
| 动作（其他）【不可重复购买相同的行动】               |   3   |
| 动作（释放戏法）                          |   3   |
| 动作（释放法术）                          | 法术环+3 |
| 附赠动作                              | 不可购买  |
| 反应                                | 不可购买  |
