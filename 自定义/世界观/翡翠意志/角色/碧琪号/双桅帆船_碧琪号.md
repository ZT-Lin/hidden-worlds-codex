# 当前状态

- 船只寿命：即将报废，龙骨充满裂痕
- 武器系统：无
- 其他结构：破旧水桶\*1，独木舟

# 便宜的船

这艘30米级的双桅帆船曾属于臭名昭彰的阿臭海贼团，据说船长是个食人魔，他们的规矩是每天吃掉一个业绩最差的船员。

我们是从[[黑金港]]的二手船市搞到这艘船的，前东家为了快速摆脱这块烫手山芋以极低的价格卖给了我们，除了总是遭遇沿途港口卫兵的盘问之外，这艘船的寿命也已经即将抵达尽头。

我们尝试过找人修复，但被告知布满龙骨的裂痕之间牵一发动全身，最好不要尝试修复，否则可能提前报废。

# 配置

碧琪号本原本配备8门黄铜船炮、一架强力巨弩、一根七米长的狰狞撞角。

但我们的钱只能勉强买下主体结构，就连里里外外的雕像、餐厅的瓷砖和船长室的玻璃窗都被卸掉了。所幸还有一只破旧的水桶和一艘救生用的独木舟因为当天的马车装不下没被收走。
