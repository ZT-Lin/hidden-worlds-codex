对于单独冒险的冒险者回合机制补偿。

冒险者单独冒险时，将会获得更多的流畅度。你可以获得额外回合，并未每个回合独立投掷先攻，具体数量等同于：$$遭遇难度系数 + 遭遇倍率（向下调整）$$

例如，你是一名一级冒险者，单独冒险，但是遭遇了 3 只地精（150xp），低于三人冒险者小队乘以下一阶倍率2.5，实际 375xp，严重超出了致命等级遭遇。

为了保证游玩体验，你可以获得 $2 + 2 = 4$ 个额外回合。

| 遭遇难度 | 系数  |
| :--- | :-: |
| 简单   |  0  |
| 中等   |  1  |
| 困难   |  1  |
| 致命   |  2  |

| 遭遇数量  | 倍数  |
| :---- | :-: |
| 1     |  1  |
| 2     | 1.5 |
| 3~6   |  2  |
| 7~10  | 2.5 |
| 11~14 |  3  |
| 15+   |  4  |
