# 万世秘录

**《万世秘录》** 是一个基于 Obsidian 构建的个人知识管理仓库，用于整理和记录以下内容：

1. **D&D 5E（2014版）核心规则**  
    以《玩家手册》《地下城主指南》《怪物图鉴》为主要规则依据，不主动引入第三方规则或变体，以保持规则体系的一致性与可溯源性。
2. **自创世界观设定**  
    包括但不限于：自建战役设定的地理、历史、神系、种族、组织、魔法理论等原创内容。
3. **战役记录**  
    记录实际跑团过程中发生的事件、NPC 行动、玩家抉择及其后果，形成可回溯的叙事档案。

# 使用方式

本仓库为纯文本 Markdown 格式，可使用 Obsidian （推荐使用 Nier 主题）直接打开，也可使用任何支持 Markdown 的编辑器阅读与编辑。
