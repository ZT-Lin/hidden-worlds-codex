# 背景

在遥远的世界边缘，坐落着一座*繁荣但孤立的地底国度*。这里四季暗无天日，地震如呼吸般频繁。*[[艾萨特_林|艾萨特 · 林 Ezaht · Lyn]]* 便诞生于这片永恒的岩层之下。然而，隔绝万物的土墙从未禁锢他的心智，反而成了他好奇心的催化剂——作为全国最杰出的*皇家亲聘科学家*，他对地表世界的渴望早已超越了学术范畴，成为一种近乎执念的信仰。

这份信仰并非空穴来风。他耗尽毕生积蓄购置钻探机所奔赴的那个坐标，源自*曾曾曾祖父留下笔记和几张残破照片*。旁人眼中模糊不清的影像碎片，在他手中却经由严谨的科学推演与从友人处习得的地理学知识，重构成了一条通往未知的精确路径。没人知道终点是星球内核还是万丈裂谷，但这恰恰是他出发的理由。*“大胆假设，小心求证。”*——这不仅是方法论，更是他身为科学家刻入骨髓的本能。国王闻讯后痛心疾首，无法理解这位国之栋梁为何要为一张旧照片抛弃一切；可对于艾萨特而言，这恰恰是对"科学家"身份最彻底的践行。

启程之日，他揣着仅剩的*5枚金币*，捋了捋*淡紫色的头发*。*宽大的耳朵*自动过滤了周遭所有的挽留与哀叹，他*一尘不染的长袍*在幽暗中划出决绝的弧线。*手杖顶端的提灯*亮起，他最后回望了一眼养育自己的土地，随即转身踏入驾驶舱，将身后的世界永远关在了舱门之外。

然而地底的意志从不轻易放行。钻探机驶入岩层深处后，*一场突如其来的地震便裹挟着轰隆巨鸣袭来*。黑暗中的震颤令他神经紧绷，双手死死握住操纵杆，每一根手指都在计算着岩壁的应力与机体的极限。震动平息后，落石已将来路彻底封死。他没有回头，甚至没有片刻沮丧——退路本就不在他的方程里。他只是重新校准了仪表，目视前方那片尚未被光照亮的未知，再次启动了引擎。
