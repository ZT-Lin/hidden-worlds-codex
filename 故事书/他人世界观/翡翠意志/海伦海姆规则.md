# 技能熟练项

游荡者8个，诗人6个，其他职业4个。自选。

# 属性Roll点

3D6×6一次过，不满意可以+3D6，相加超过20爆点锁到8。可反复叠加。

# 语言

除了母语和通用语外，每拥有1点智力调整值可自选1种额外语言（除德鲁伊语等密语暗语外）。

如不想学习语言，可以替换成对一项技能、工具、手艺的熟练。

本作品中可能用到的有裁缝、文学、木匠、风族语、演讲、炼金工具、古董修复、贵族礼仪、外交辞令、政治手腕。

# 移动中隐匿

从全身掩护状态重新暴露在敌方视野中时可使用附赠动作尝试隐匿。

# 医疗包

主要动作进行互动，治疗效果1D4+1。直到完成长休前无法重复受到此治疗效果。

对生命值至少为1的目标使用难度10，对生命值为0的目标使用难度15。

# 法术材料包

为消耗价值不超过1金币材料的法术提供必须成分。

# 锈蚀/发霉的武器

攻击检定掷出1时损毁。

# 拼凑护甲

提供13/15/17（轻甲/中甲/重甲）的护甲等级，最大敏捷加值为0，敏捷相关检定具有劣势，在受到重击时解体。
