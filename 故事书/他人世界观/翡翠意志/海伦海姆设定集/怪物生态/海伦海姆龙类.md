# 响雷“女”士

海伦海姆的龙类是没有性别之分的，但在凡人的文化中每一头巨龙都被赋予了性别身份。例如“晌雷女士”欧斯特拉，就因龙群中大多数龙类都是她的后代而得名。

# 繁殖

它们会在进入青年期后不定期产卵。龙蛋的大小近似一只可以被人类环抱的宝箱。

- 幼龙破壳时是小体型，并且会在100天内成长至大体型（5级）。
- 幼年龙在50年后进入青年期，迎来第二次发育，在10年内成长至超巨型（20级）。
- 体型成长到极限的巨龙会以每个百年1级的速度缓慢提升能力。

通过奥术仪式可能会孵化出双足飞龙、地龙或龙人，但只有顺应龙神意志降生的才是真龙。龙类也可以变形成有性繁殖的生物孕育后代，这种方式常见于金属龙与类人生物之间。

# 消化

龙的消化系统强大到就连无机物也能吸收得一干二净，因此没有类似泄殖腔的结构，产卵也是通过类似反刍的动作进行的。

# 龙魔法

龙的魔法能力通常会在青年期觉醒，并在千年后登峰造极，这是一个自然而然的过程，无需钻研或训练。10级起，习得所有牧师戏法；11级起如同1级术士般获得法术环位，并随等级提升。所有已解锁的环位等级包含的牧师法术以及相关领域法术视为已知法术。

一些巨龙会习得更适合自身特性或习性的能力作为牧师能力的替代，例如偏好栖息于森林的绿龙可能习得德鲁伊能力。
