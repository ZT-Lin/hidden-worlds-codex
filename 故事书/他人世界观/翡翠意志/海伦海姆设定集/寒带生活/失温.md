# 保暖

在冬季，保暖离不开棉衣。

室外的寒冷需要每分钟进行一次体质豁免抵抗失温，一件品质优良的棉衣可以把这个周期延长至2D4小时，一件破旧的棉衣也可以在第一个小时免受寒冷侵袭。

好的棉衣7金币一件，破旧的棉衣也要7银币一件，同样品质的棉衣在黑市以两倍价钱出售。

**“我不能吃肉吗？”**

可以，但由于缺乏热量，在寒冷的日子里依靠肉食补充的营养只能支撑相当于体质调整值的天数。超过自身能承受的极限天数未补充营养则无法维持体温，离开篝火1分钟失温。

# 失温等级

处于失温状态的生物会根据不同的失温等级受到周期性的冰冻伤害。

靠近篝火取暖可以暂时免受伤害，在篝火旁完成短休可以重新进行豁免检定，完成长休则终止失温状态。

处于失温状态的生物每次受到冰冻伤害都必须通过体质豁免，否则提升1个失温等级。

**1**级失温：每10分钟受到1点冰冻伤害。

**2**级失温：每分钟受到1点冰冻伤害。

**3**级失温：每轮受到1点冰冻伤害并提升1级力竭。
