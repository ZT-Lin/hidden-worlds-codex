# 视觉

你的手上发出闪电，并对你触碰的一个生物发动电击。

# 效果

对目标发动一次近战法术攻击。如果目标穿着金属护甲，则你进行该检定时具有优势。若命中，则目标受到 1d8 点闪电伤害，并且在其下一回合开始前不能执行任何反应。

你到达 5 级时，该法术的伤害增加 1d8 （变为 2d8） 。 11 级时再加 1d8（变为 3d8），17 级时再加 1d8（变为 4d8）。
