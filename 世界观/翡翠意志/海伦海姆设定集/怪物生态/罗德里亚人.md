# 遗民

这些以丹王朝的遗民除了躲在安达洛瑟羽翼下的圣城居民外，大多数地区的罗德里亚人都难逃边缘化的命运。

# 外貌

仅从外貌上他们就与其他人类大不相同，深棕色的皮肤和黑色的头发，就算与其他类人生物结合的混血后代都会十分扎眼。

由于长期的分化，人们通常可以仅凭口音、举止或气质就判断出眼前的罗德里亚人究竟是下城区的骗子还是远方的贵客。

# 特性

| 特性       | 效果                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------- |
| **强光抗性** | 其他生物无法借助太阳作为针对罗德里亚人的掩护，即便是在沙漠旱季的正午也不会视野收缩。<br>此外，罗德里亚人对导致目盲的强光效应的豁免具有优势。                                        |
| **高温耐力** | 抵抗炎热环境的体质豁免具有优势。                                                                                                |
| **古典气质** | 对类人生物的社交技能检定具有优势。                                                                                               |
| **高原血统** | 抵抗高原反应的体质豁免具有优势；在非高原地区的运动检定具有优势。                                                                                |
| **社群风俗** | 获得运动、驯兽、弯刀的熟练项，并且可以把弯刀作为施法的法器。                                                                                  |
| **占星术**  | 将占卜术、预言术、通神术、通晓传奇和预警术加入已知法术列表。<br>可通过仪式施放这些法术而无需消耗法术环位，但需消耗价值 **15/50/150/500/1500** 金币的香薰。<br>每日可使用次数等于其智力调整值。 |
| **语言**   | 罗德里亚人的母语是风族语，同时会说通用语和龙语。                                                                                        |
